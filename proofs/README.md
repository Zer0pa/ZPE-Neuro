# Proof Surface

This repo carries a curated proof subset from the adjudicated Neuro bundle:

`proofs/selected_artifacts/2026-02-21_zpe_neuro_wave1_closure_push_adjudicated/`

## What Is Included

- claim summaries
- gate summaries
- falsification record
- risk and commercialization notes
- runpod/readiness metadata
- key benchmark and codec evidence JSON files

## What Is Intentionally Excluded

- raw session directories
- sorter scratch directories
- full historical artifact trees
- large runtime byproducts that are better kept outside git

## Why

The goal of this repo is a clean private staging boundary, not a full archive transplant. The selected subset preserves the decision-critical proof files while keeping the repo inspectable.
