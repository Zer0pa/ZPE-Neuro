# Governance

This repo is governed by evidence-backed status language.

## Core Rules

- runtime and artifact truth outrank prose
- contradictions are retained, not averaged away
- unresolved items stay unresolved until a replacement artifact exists
- private staging is the default until explicit verification and release gates are cleared

## Status Semantics

- `PASS`: the cited artifact supports the stated gate or measurement within scope
- `INCONCLUSIVE`: evidence conflict or missing support remains
- `FAIL`: the relevant gate is not met
- `OPEN`: risk or commercialization posture is not closed

## Current Governance Constraint

This repo is a private staged boundary, not the final release authority surface. Phase 5 verification still has to confirm clean-clone behavior before this repo can be treated as a release candidate.
