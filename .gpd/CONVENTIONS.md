# Conventions

## Active Project Conventions

- Signal amplitudes are tracked in microvolts after any source-unit conversion.
- Sample windows use zero-based half-open ranges: `[start, start + sample_limit)`.
- Candidate windows are evaluated in deterministic ascending start order.
- The authoritative code and evidence surface is the inner repo, not the outer workspace.

## Not Yet Locked

- Broader mathematical notation conventions are not yet material to this lane and remain unset unless execution requires them.
