# Notation Glossary

| Symbol / Term | Meaning |
| --- | --- |
| `N_w` | window length in samples |
| `C` | channel count in the evaluated slice |
| informative window | a candidate slice with enough activity or eventfulness to be decision-grade |
| quiet window | a slice whose high compression could be a false positive because the codec does not meaningfully engage it |
| first lane | the narrowest product family that can be defended with current authority evidence |
