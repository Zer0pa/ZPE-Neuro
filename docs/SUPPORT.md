<p>
  <img src="../.github/assets/readme/section-bars/what-gets-a-fast-response.svg" alt="WHAT GETS A FAST RESPONSE" width="100%">
</p>

Fastest responses usually include:
- reproducible steps
- exact commands
- artifact paths
- a specific contradiction or failure signature

<p>
  <img src="../.github/assets/readme/section-bars/what-does-not-get-a-response-here.svg" alt="WHAT DOES NOT GET A RESPONSE HERE" width="100%">
</p>

These will be sent back for clarification:
- vague failure claims without files or commands
- evidence disputes without counter-evidence
- requests that assume public-release status that this repo does not currently have

<p>
  <img src="../.github/assets/readme/section-bars/response-expectations.svg" alt="RESPONSE EXPECTATIONS" width="100%">
</p>

This is a private staged repository maintained by a small team. We aim to:
- acknowledge issues within 48 hours
- triage within 7 days
- prioritize security reports according to `SECURITY.md`
