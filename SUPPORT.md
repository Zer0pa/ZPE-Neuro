# Support

## Routing

| Need | Route |
|---|---|
| bug report | GitHub issue in this repo |
| evidence dispute | GitHub issue with artifact references |
| general question | GitHub issue |
| security vulnerability | `architects@zer0pa.ai` |
| code of conduct report | `architects@zer0pa.ai` |
| licensing question | `architects@zer0pa.ai` |

## What Gets A Fast Response

- reproducible steps
- artifact paths
- exact command output
- concrete contradiction reports

## What Will Be Sent Back For Clarification

- vague failure claims without files
- assertions that omit the relevant proof artifact
- requests that assume public-release status that this repo does not yet have
